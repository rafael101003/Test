## 👁️ Visão Geral

O **Tela de Login** é um projeto front-end desenvolvido por [Rafael](https://github.com/rafael101003) focado na criação de uma página de autenticação limpa, acessível e responsiva. O objetivo principal é servir como um modelo (template) robusto para aplicações web de diversos portes.

### ✨ Destaques
- **Design Responsivo:** Funciona perfeitamente em dispositivos móveis, tablets e desktops.
- **UI/UX Moderna:** Efeitos visuais suaves, transições limpas e foco na usabilidade.
- **Código Limpo e Organizado:** Fácil de entender, customizar e expandir.

---

## ⚙️ Funcionalidades

- [x] **Campo de Entrada de Usuário/E-mail** com validação visual.
- [x] **Campo de Senha** com funcionalidade para alternar visibilidade (ocultar/mostrar senha).
- [x] **Botão de Envio (Submit)** com efeitos de hover e estado ativo.
- [x] **Opção "Lembrar de mim"** (Checkbox interativo).
- [x] **Links de Redirecionamento:**
  - "Esqueceu a senha?"
  - "Criar uma conta" / "Cadastre-se"
- [x] **Suporte a Validação Básica:** Feedback visual para dados incompletos ou incorretos.

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando as seguintes tecnologias e ferramentas:

| Tecnologia | Descrição |
| :--- | :--- |
| **HTML5** | Estruturação semântica da página |
| **CSS3** | Estilização, animações e layout responsivo (Flexbox/Grid) |
| **JavaScript (ES6+)** | Lógica de interação, animações e validação de campos |
| **Font Awesome / Lucide** *(opcional)* | Ícones visuais de suporte |
